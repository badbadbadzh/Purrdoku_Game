# PURRDOKU

A cozy cat logic puzzle. One HTML file, with responsive desktop and mobile layouts.

## Play

Download and open `index.html` in a modern browser. No installation or build step is required.

- Place one cat in each row, column, and colored region.
- Cats cannot touch, including diagonally.
- Mark impossible cells and use automatic marking to help solve the board.
- You have three hearts. Incorrect placements cost a heart.

Includes randomized boards, puzzles up to 10 × 10, a coin and undo-ticket shop, custom cat images, and optional Bilibili playback.

Progress and preferences are saved in your browser. They are not synced across devices or browser origins. Bilibili playback requires an internet connection and is subject to the video's embedding availability.

## Publish with GitHub Pages

1. Commit these files and publish the repository to GitHub.
2. Open the repository on GitHub, then go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Choose **main** and **/(root)**, then click **Save**.
5. When deployment completes, open the site URL shown on the Pages settings page.

For subsequent updates, replace `index.html`, commit the changes, and push to GitHub.
